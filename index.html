Product

The Four Pillars

One local model (via LM Studio) is the sole generation brain for every output the app produces. Skills, guardrails, and schema validation engineered into the app prevent hallucination — not a bigger model.

📚

Learning Journeys

Interactive HTML learning experiences with cards, quizzes, and evaluations on any topic.

  • Generate → render → export in one flow
  • PDF, DOCX, PPTX, XLSX, TXT, audio
  • Revisitable, modifiable, extendable
🗣️

Language Lab

The flagship. Two-voice dialogue, vocab flashcards, grammar drills, listening comprehension, and evaluations — all in an interactive HTML lesson pack.

  • LessonPack generation with schema validation
  • Deterministic grading + model-judge fallback
  • Spaced repetition (SM-2) across sessions
  • Per-segment audio via Voice Catalog

Architecture

How It's Built

Chunked, not monolithic. Every engine is independently deletable and rebuildable. Correctness comes from the Generation Pipeline — the one Guardrail Loop — not from model size.

Generation Pipeline

The single deep module that owns every generation: render prompt → call model → extract JSON → validate → retry with feedback → typed error. All engines register a template + validator; none hand-roll the loop.

Voice Catalog

The one table mapping (language, role) → TTS voice. Narration, podcasts, and Language Lab resolve voices only through it. Provisioning checks + download helpers for offline setup.

Storage

File-based persistence for every artifact kind (journeys, resumes, packs, media, verdicts, capabilities) plus preferences. Secrets adapter consolidates all third-party credential loading.

Shell Controller

All UI logic behind ShellController returning typed FlowResult envelopes. Error taxonomy maps to dialog kinds with actionable details — never raw tracebacks.

Connector Hub

Single adapter seam for external services: capabilities(), send(), poll(). Keyless-first (HF Spaces, Pollinations), then auth-based (Figma). Failures are data, not exceptions.

Audio Assembly

Public render_segments() seam for all audio consumers. Narration, podcasts, bilingual, immersion, and Language Lab all route through it — zero private cross-engine imports.

Career Agent

Job-Board Search Agent

Automatically hunts across keyless job boards, ranks by relevance, and prepares full application packages — with direct links for human submission.

🔍 Search

Keyless connectors for three job boards:

  • Greenhouse — v1 boards-api, 162+ listings verified
  • Ashby — public posting API
  • RemoteOK — remote-only worldwide

Keyword matching with title×3 + snippet×1 scoring. Cross-source URL dedupe. Dead-board isolation (logged, never fatal).

📦 Prepare

Full application package per listing:

  • Enhanced resume → PDF + DOCX
  • Grounded cover letter (150–250 words)
  • Listing reference file with URL

Stored in exports/applications/<company>-<role>/. The agent finds and prepares — you submit.

🔔 Watch

Saved searches with diff-based polling:

  • Role, location, company filters persisted
  • Seen-URL set tracks what you've already seen
  • Reports only NEW listings each check
  • Auto-check every 10 minutes from the UI

Get Started

Quick Start

1. Install LM Studio

Download from lmstudio.ai, load a tool-calling model (gemma-4-12B-it-QAT recommended), start the local server on localhost:1234.

2. Install Dependencies

pip install -r requirements.txt
Optional: pip install piper-tts for offline audio.

3. Launch

python desktop-shell/app.py
The desktop window opens with all six tabs ready.
