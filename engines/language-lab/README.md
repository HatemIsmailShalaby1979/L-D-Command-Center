# Language Lab

The language-lab engine specializes in language-learning podcast generation, producing two distinct modes: bilingual podcasts (with a host speaking the target language and a second host translating word-by-word or sentence-by-sentence into the user's known language) and immersion podcasts (where both voices speak only the target language, simulating a natural target-language podcast experience). It serves the "Speak Like an Alien" mode — a distinct journey type focused entirely on language acquisition through audio. If this engine is deleted, all language-learning podcast content and dual-mode audio generation is lost.
